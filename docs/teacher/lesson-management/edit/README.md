# 수업 수정하기

수업의 제목, 썸네일, 문장, 단어, 문제를 수정할 수 있습니다.

{% hint style="warning" %}
수업을 수정해도 이미 출제한 과제는 변경되지 않습니다. 수정 내용은 새 과제부터 반영됩니다.
{% endhint %}

### 수업 정보 수정하기

1. 왼쪽 사이드바에서 **수업관리**를 선택합니다.
2. 수정할 수업의 **⁝** 메뉴를 선택합니다.
3. **정보 변경**을 선택합니다.
4. 제목 또는 썸네일을 변경한 후 저장합니다.

### 수업 콘텐츠 수정하기

1. **수업관리**에서 수정할 수업의 **⁝** 메뉴를 선택합니다.

<figure><img src="../../../.gitbook/assets/스크린샷 2026-04-01 오후 5.14.21.png" alt="수업 목록의 더보기 메뉴"><figcaption><p>수정할 수업의 더보기 메뉴를 선택합니다.</p></figcaption></figure>

2. **수업 수정**을 선택합니다.

<figure><img src="../../../.gitbook/assets/스크린샷 2026-04-01 오후 5.15.46.png" alt="수업 수정 메뉴"><figcaption><p>수업 수정 메뉴를 선택합니다.</p></figcaption></figure>

3. 안내를 확인한 후 **수업 수정**을 선택합니다.

<figure><img src="../../../.gitbook/assets/스크린샷 2026-04-01 오후 5.16.26.png" alt="수업 수정 전 안내 화면"><figcaption><p>수정 사항은 새 과제부터 반영됩니다.</p></figcaption></figure>

4. 상단 탭에서 수정할 콘텐츠를 선택합니다.

* **문장**: 학습 문장과 번역을 수정합니다.
* **싱크**: 음원 또는 영상의 문장 구간을 조정합니다.
* **단어**, **문제**, **책**: 각 콘텐츠를 추가하거나 수정합니다.

<figure><img src="../../../.gitbook/assets/스크린샷 2026-04-01 오후 5.17.27.png" alt="수업 수정 화면의 콘텐츠 탭"><figcaption><p>콘텐츠별 탭에서 필요한 항목을 수정합니다.</p></figcaption></figure>

5. 수정을 완료한 후 화면 하단의 **수정하기**를 선택합니다.

{% hint style="info" %}
문장 수정의 상세 방법은 [sentence.md](sentence.md "mention")에서 확인할 수 있습니다.
{% endhint %}
