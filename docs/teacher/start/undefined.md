# 회원 탈퇴

회원 탈퇴는 계정과 계정 내 모든 데이터를 삭제하는 절차입니다.

{% hint style="danger" %}
**회원 탈퇴는 되돌릴 수 없습니다**

탈퇴하시면 계정 내 모든 데이터와 권한이 삭제되며, 다시 가입하셔도 복구되지 않습니다.\
요금 청구만 중단하고 싶으시다면 **회원 탈퇴가 아닌** [**구독 해지**](/broken/pages/6d26c100d48408d8259a638210c4247bf43041d8) 를 이용해 주세요.
{% endhint %}

{% hint style="info" %}
**이런 경우에는 구독 해지를 선택해 주세요**

* 당분간 사용하지 않지만 나중에 다시 이용할 수도 있는 경우
* 요금 청구만 중단하고 싶은 경우
* 수업 자료나 학생 학습 기록을 남겨두고 싶은 경우

구독 해지 방법은 [해지 및 환불](/broken/pages/6d26c100d48408d8259a638210c4247bf43041d8) 문서를 참고해 주세요.
{% endhint %}

### 탈퇴 시 삭제되는 항목

탈퇴가 완료되면 아래 항목이 모두 삭제되며 복구되지 않습니다.

* 계정 정보 및 로그인 권한
* 등록하신 학생 계정
* 생성하신 수업 자료 및 커리큘럼
* 과제 및 학생 학습 데이터
* 리포트 등 모든 기록

### 탈퇴 전에 확인해 주세요

{% stepper %}
{% step %}
#### 필요한 자료를 저장해 주세요

학습지, 리포트 등 보관이 필요한 자료는 탈퇴 전에 내려받아 주세요.\
탈퇴 후에는 어떤 방법으로도 복구하실 수 없습니다.
{% endstep %}

{% step %}
#### 구독 상태를 확인해 주세요

이용 중인 구독이 있다면 해지 및 환불 기준을 먼저 확인해 주세요.\
자세한 내용은 [해지 및 환불](../billing/cancel.md) 문서를 참고해 주세요.
{% endstep %}

{% step %}
#### 학생과 학부모에게 안내해 주세요

학생 계정이 함께 삭제되므로, 학습을 이어가실 수 없게 됩니다.\
필요하시다면 미리 안내해 주세요.
{% endstep %}
{% endstepper %}

### 탈퇴 신청 방법

회원 탈퇴는 관리자 페이지에서 직접 처리하실 수 없습니다.\
고객센터로 문의해 주시면 확인 후 처리해 드립니다.

{% hint style="info" %}
원아워 고객센터 연락처&#x20;

* 원아워 대표 번호 > 02-3285-1230
* 원아워 채팅 문의 > 1hour.channel.io 혹은 원아워 로그인 후 화면 오른쪽 하단 채팅버튼 클릭

영업일 기준 오전 9시부터 오후 6시까지 운영하고 있습니다.
{% endhint %}

### 자주 묻는 질문

<details>

<summary>요금만 안 나가게 하고 싶어요. 탈퇴해야 하나요?</summary>

아닙니다. **구독 해지**를 하시면 됩니다.\
해지하시면 요금 청구가 중단되고, 학생 계정과 수업 자료는 그대로 유지됩니다.

자세한 내용은 [해지 및 환불](/broken/pages/6d26c100d48408d8259a638210c4247bf43041d8) 문서를 참고해 주세요.

</details>

<details>

<summary>탈퇴한 계정을 되살릴 수 있나요?</summary>

되살릴 수 없습니다.\
탈퇴 시 계정 내 모든 데이터가 삭제되며, 같은 정보로 다시 가입하셔도 이전 데이터는 복구되지 않습니다.

</details>

<details>

<summary>탈퇴하면 학생 계정은 어떻게 되나요?</summary>

등록하신 학생 계정도 함께 삭제됩니다.\
학생의 학습 기록 역시 복구되지 않으므로, 필요한 자료는 미리 저장해 주세요.

</details>

<details>

<summary>탈퇴하려면 구독을 먼저 해지해야 하나요?</summary>

이용 중인 구독이 있으시다면 채널톡으로 문의해 주세요.\
구독 처리와 탈퇴를 함께 안내해 드립니다.

</details>

<details>

<summary>탈퇴하지 않고 잠시 쉬어갈 수 있나요?</summary>

구독을 해지하시면 요금 청구가 중단되고 데이터는 유지됩니다.\
다시 이용하실 때 결제하시면 이전 자료를 그대로 사용하실 수 있습니다.

</details>

### 문의
