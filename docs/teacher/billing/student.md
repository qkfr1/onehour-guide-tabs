# 비즈니스 파트너 플랜

비즈니스 파트너 플랜은 교육 기관이 설정한 수강료를 학생이 직접 결제하고, 원아워 이용료와 수수료를 제외한 수익금을 원장님께 환급해 드리는 수익 공유형 요금제입니다.

### 4. 보증금

원아워 서비스 유지를 위한 최소 학생 수는 10명으로 설정되어 있습니다.&#x20;

따라서 실제 인원과 관계없이 **10명분 이용료에 해당하는 금액이 보증금으로 선결제**되며, 정산 시 반환됩니다.

실제 결제한 학생이 10명 미만인 경우, 부족한 학생의 이용료를 제하고 반환됩니다.

| 플랜          | 보증금      |
| ----------- | -------- |
| Basic       | 59,000원  |
| Speaking AI | 79,000원  |
| Writing AI  | 79,000원  |
| AI Pro      | 120,000원 |

보증금은 매월 결제되며,  **익월 영업일 기준 첫날** 정산 시 반환됩니다.

***

### 5. 정산 및 수익 구조

정산은 매월 학생이 결제한 총액에서 운영비를 공제한 후, **익월 영업일 기준 첫날** 지정 계좌로 입금됩니다.&#x20;

정산일이 휴일인 경우 다음 영업일로 이연됩니다.

#### 5-1. 산정 방식

<table><thead><tr><th width="292.953125">항목</th><th>산정 방식</th></tr></thead><tbody><tr><td>학생 결제 최소 금액</td><td>플랜별 최소 금액 이상</td></tr><tr><td>원아워 이용료</td><td><strong>선택하신 플랜의 학생 1인당 요금</strong> (일할 계산 적용)</td></tr><tr><td>원아워 수수료</td><td>전체 결제 금액의 10%</td></tr><tr><td>부가세</td><td>(결제 금액 − 이용료 − 수수료) ÷ 11</td></tr><tr><td>최종 수익금</td><td>학생 결제 금액 − 이용료 − 수수료 − 부가세</td></tr><tr><td>원천징수 세금</td><td>최종 수익금의 3.3% (소득세) *10원 단위 절사</td></tr></tbody></table>

#### 5-2. 정산 흐름

```
학생 결제 총액
  − 원아워 이용료 (플랜 요금 × 결제 학생 수, 일할)
  − 원아워 수수료 (결제 총액의 10%)
  − 부가세 ((결제 총액 − 이용료 − 수수료) ÷ 11)
= 최종 수익금
  − 원천징수 3.3% (10원 단위 절사)
= 환급액
```

#### 5-3. 계산 예시

AI Pro 플랜, 학생 30명, 학생당 15,000원으로 설정한 경우

| 항목                                      | 금액          |
| --------------------------------------- | ----------- |
| 학생 결제 총액 (15,000원 × 30명)                | 450,000원    |
| 원아워 이용료 (12,000원 × 30명)                 | −360,000원   |
| 원아워 수수료 (10%)                           | −45,000원    |
| 부가세 ((450,000 − 360,000 − 45,000) ÷ 11) | −4,090원     |
| **최종 수익금**                              | **40,910원** |
| 원천징수 3.3% (10원 단위 절사)                   | −1,350원     |
| **환급액**                                 | **39,560원** |

***

### 6. 소득 신고

* 환급되는 금액은 사업소득으로 처리되며, 세금 3.3%가 원천징수됩니다.
* 지급 시 다음 정보를 기준으로 소득신고가 이루어지기 때문에 별도의 신고가 필요하지 않습니다.
  * 성명, 은행명, 계좌번호, 소득금액, 소득일자
  * 「소득세법 시행령」 제216조의3

### 7. 학부모 알림톡

학부모 알림톡 기능은 비즈니스 파트너 플랜 정산과 **별도로 운영**됩니다.

<table><thead><tr><th width="179.79296875">항목</th><th>내용</th></tr></thead><tbody><tr><td>정산 반영</td><td>환급액에서 차감되지 않음</td></tr><tr><td>결제 방식</td><td><strong>보증금 결제에 등록하신 카드에서 자동 결제</strong></td></tr><tr><td>환불</td><td>발송된 알림톡 비용은 학생 구독권 환불 여부와 관계없이 환불 불가</td></tr></tbody></table>

알림톡 비용은 원장님께서 부담하시는 비용이며, 정산 환급액과 무관하게 등록된 카드로 청구됩니다.

### 8. 수업 생성 AI 크레딧

비즈니스 파트너 플랜도 수업 생성 AI 크레딧(CP)이 적용됩니다.

#### 8-1. 지급 기준

크레딧은 학생이 납부하는 금액 중 **원아워 이용료를 기준으로** 지급되며, 아카데미 플랜보다 높은 지급 비율이 적용됩니다.

| 플랜          | 지급 비율    | 학생 1명당 지급 크레딧 |
| ----------- | -------- | ------------- |
| Basic       | 이용료의 15% | 약 44 CP       |
| Speaking AI | 이용료의 17% | 약 67 CP       |
| Writing AI  | 이용료의 17% | 약 67 CP       |
| AI Pro      | 이용료의 20% | 약 120 CP      |

(1 CP = 20원 기준 환산)

**학원 규모별 예시**

| 학생 수 | Basic      | Speaking · Writing AI | AI Pro     |
| ---- | ---------- | --------------------- | ---------- |
| 10명  | 약 443 CP   | 약 672 CP              | 약 1,200 CP |
| 30명  | 약 1,328 CP | 약 2,015 CP            | 약 3,600 CP |
| 50명  | 약 2,213 CP | 약 3,358 CP            | 약 6,000 CP |

#### 8-2. 지급 시점과 유효기간

| 항목        | 기준                       |
| --------- | ------------------------ |
| 지급 시점     | 학생 결제 완료 시점 (학생별 실시간 지급) |
| 유효기간      | 지급 당월 말까지 (이월 불가)        |
| 추가 구매 크레딧 | 구매일로부터 1년                |

#### 8-3. 크레딧 회수

**학생이 환불되면 해당 학생분으로 지급된 크레딧이 즉시 회수됩니다.**

이미 크레딧을 사용하신 뒤 학생 환불이 발생하면 잔액이 마이너스로 표시될 수 있습니다.

* 마이너스 크레딧은 **50 CP 이상일 때 매일 오전 9시에 일괄 청구**됩니다.
* 마이너스 상태에서는 AI 수업 생성 기능이 제한됩니다.

학생 환불이 예상되는 시점에는 크레딧 사용에 유의해 주시기 바랍니다.

크레딧 사용량, 환불 기준 등 자세한 내용은 \[크레딧(CP) 안내] 문서를 참고해 주세요.

***

### 9. 학생 퇴원 시

원아워는 실시간 계정 관리 시스템을 사용하므로 퇴원 처리에 주의가 필요합니다.

* **학생 퇴원 시**: 다음 달 정기 결제를 방지하려면 반드시 전월 말일까지 학생 계정을 삭제해야 합니다.
* **권한 회수**: 학생 계정을 삭제하는 즉시 해당 학생의 이용 권한은 소멸됩니다.
* 삭제 즉시 데이터와 권한이 회수되므로 복구가 어렵습니다. 퇴원 처리는 해당 학생의 당월 학습이 완전히 종료된 후 진행해 주시기 바랍니다.

***

### 10. 이용 중단 — 구독권 해지

학원 전체가 비즈니스 파트너 플랜 이용을 중단하고자 하실 경우 아래 절차를 진행해 주세요.

1. 관리자 페이지 좌측 하단 \[이름-기관명] 프로필 클릭
2. \[구독 결제 관리] > \[구독권 해지] 버튼 클릭

**주의**: 반드시 전월 말일까지 해지를 완료해야 다음 달 정기 결제 및 보증금 청구가 발생하지 않습니다.

### 11. 환불 정책

#### 11-1. 구독권 환불 기준

학생이 결제한 구독권의 환불 기준입니다.

| 시기       | 환불 요청 시기            | 가능 여부      |
| -------- | ------------------- | ---------- |
| 이전 달 결제분 | —                   | 환불 불가      |
| 이번 달 결제분 | 정기결제 후 영업일 기준 2일 이내 | 전액 환불      |
| 이번 달 결제분 | 정기결제 후 7일 이내 미사용    | 전액 환불      |
| 이번 달 결제분 | 정기결제 후 3일 이후 사용     | 일할 계산 후 환불 |

전월 처리 누락 등 불가피한 사유의 경우 일할 계산을 적용하여 부분 환불이 가능합니다.

#### 11-2. 환불 발생 시 정산 처리

| 항목        | 처리                           |
| --------- | ---------------------------- |
| 정산 대상     | 해당 월 결제에 성공한 학생              |
| 환불된 학생    | 정산에서 제외                      |
| 결제 실패 학생  | 정산 제외 (권한 자동 회수)             |
| 중도 결제 학생  | 일할 계산하여 정산 반영                |
| 무료 크레딧    | 환불 즉시 회수 (8-3 참고)            |
| 추가 구매 크레딧 | 구매일로부터 30일 이내 미사용분에 한해 환불 가능 |
| 알림톡 비용    | 환불 불가                        |

#### 11-3. 신청 경로

환불은 관리자 페이지에서 직접 신청하실 수 없습니다.&#x20;

채널톡 또는 담당 매니저에게 문의해 주시면 확인 후 처리해 드립니다.

### 12. 자주 묻는 질문

**정산 내역은 어디서 확인할 수 있나요?**&#x20;

정산 시점에 카카오 알림톡으로 정산 안내가 발송됩니다. 안내된 링크를 통해 상세 내역이 포함된 PDF 명세서를 확인하실 수 있습니다.

**정산일이 언제인가요?**&#x20;

익월 영업일 기준 첫날에 일괄 처리됩니다. 해당일이 휴일인 경우 다음 영업일로 이연됩니다.

**학생이 10명 미만인데 보증금은 왜 발생하나요?**&#x20;

원아워 서비스 유지를 위한 최소 학생 수는 10명으로 설정되어 있습니다. 따라서 인원과 관계없이 10명분 이용료에 해당하는 금액이 보증금으로 선결제됩니다.

**플랜을 변경할 수 있나요?**&#x20;

플랜은 계약 시 지정됩니다. 변경을 원하시는 경우 담당 매니저에게 문의해 주세요.

**실수로 학생을 삭제했는데 복구가 가능한가요?**&#x20;

삭제 즉시 데이터와 권한이 회수되므로 복구가 어렵습니다. 퇴원 처리는 반드시 해당 학생의 당월 학습이 완전히 종료된 후 진행해 주시기 바랍니다.

**학생이 환불받으면 크레딧은 어떻게 되나요?**&#x20;

해당 학생분으로 지급된 크레딧이 즉시 회수됩니다. 이미 사용하신 경우 잔액이 마이너스가 될 수 있으며, 50 CP 이상일 때 매일 오전 9시에 일괄 청구됩니다.

**알림톡 비용도 정산에서 차감되나요?**&#x20;

차감되지 않습니다. 알림톡 비용은 정산과 별도로 보증금 결제에 등록하신 카드에서 자동 결제됩니다.
