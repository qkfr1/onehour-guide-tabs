# 해지 및 환불

원아워 구독을 해지하는 방법과 환불 기준을 안내드립니다.

{% hint style="info" %}
**해지와 환불은 별개입니다**

해지하시면 결제하신 기간이 끝날 때까지 이용하신 후 종료됩니다. 이 경우 환불은 발생하지 않습니다.\
지금 바로 종료하고 남은 금액을 돌려받으시려면 **중도 해지**를 별도로 요청하셔야 합니다.
{% endhint %}

### 4. 환불 기준

환불 가능 여부는 아래 순서로 확인하시면 됩니다.

#### 4-1. 전액 환불에 해당하는 경우

아래 조건에 해당하시면 결제 방식과 관계없이 전액 환불이 가능합니다.

<table><thead><tr><th width="360">조건</th><th>가능 여부</th></tr></thead><tbody><tr><td>결제 후 영업일 기준 2일 이내 (사용 여부 무관)</td><td>전액 환불</td></tr><tr><td>결제 후 7일 이내이며 활동 이력이 전혀 없는 경우</td><td>전액 환불</td></tr><tr><td>이전 달 결제분</td><td><strong>환불 불가</strong></td></tr></tbody></table>

#### 4-2. 월간 결제 중도 해지

전액 환불 조건에 해당하지 않으시면 **당월 결제분에 대한 환불은 없습니다.**\
당월 말일까지 이용하신 후 익월부터 청구가 중단됩니다.

#### 4-3. 연간 결제 중도 해지

**할인 적용 전 정가**를 기준으로 사용 기간을 환산한 뒤, 사용하신 크레딧을 차감하여 환불액을 산정합니다.

```
환불액 = 결제 금액 − 사용 기간 정가 환산액 − 사용 크레딧 환산액

· 사용 기간 정가 환산액 = (정가 연 이용료 × 시트 수 ÷ 365) × 사용 일수
· 사용 크레딧 환산액 = 사용 크레딧(CP) × 20원
```

<details>

<summary>계산 예시 — AI Pro 30시트, 152일 사용, 크레딧 3,000 CP 사용</summary>

<table><thead><tr><th width="360">항목</th><th>금액</th></tr></thead><tbody><tr><td>결제 금액 (106,920원 × 30개)</td><td>3,207,600원</td></tr><tr><td>정가 기준 연 이용료 (118,800원 × 30개)</td><td>3,564,000원</td></tr><tr><td>사용 기간 정가 환산액 (3,564,000 ÷ 365 × 152일)</td><td>−1,484,186원</td></tr><tr><td>사용 크레딧 환산액 (3,000 CP × 20원)</td><td>−60,000원</td></tr><tr><td><strong>환불액</strong></td><td><strong>1,663,414원</strong></td></tr></tbody></table>

</details>

{% hint style="info" %}
연간 결제 환불은 **할인 전 정가**로 사용 기간을 환산합니다.\
할인받으신 금액이 아닌 정가 기준으로 사용분이 차감되는 점을 참고해 주세요.
{% endhint %}

### 5. 학생이 그만두었을 때의 환불

{% hint style="warning" %}
**학생을 삭제하는 것만으로는 환불되지 않습니다**

원아워는 학생이 아닌 **시트 단위로 과금**됩니다.\
학생을 삭제하셔도 시트는 비어 있는 상태로 유지되므로 요금이 변동되지 않습니다.
{% endhint %}

#### 5-1. 환불받으시려면

<table><thead><tr><th width="220">처리</th><th>결과</th></tr></thead><tbody><tr><td>학생만 삭제</td><td>요금 변동 없음. 비어 있는 시트가 남습니다.</td></tr><tr><td>학생 삭제 + <strong>시트 삭제</strong></td><td>줄어든 시트 수만큼 요금이 조정됩니다.</td></tr></tbody></table>

요금을 줄이시려면 관리자 페이지에서 **시트 수를 함께 줄여** 주셔야 합니다.\
시트를 삭제하는 방법은 [시트 추가 · 삭제](https://1hour.gitbook.io/guide/~/revisions/H6SuWSC7TrvHNKOtOJdh/teacher/student-management/seats) 문서를 참고해 주세요.

#### 5-2. 시트 삭제 시 환불 기준

<table><thead><tr><th width="140">구분</th><th>처리</th></tr></thead><tbody><tr><td>월간 결제</td><td>일할 계산하여 익월 정산에 환불이 반영됩니다.</td></tr><tr><td>연간 결제</td><td><strong>환불되지 않습니다. 비어 있는 시트에 1년 이내 다른 학생을 등록해 사용하실 수 있습니다.</strong></td></tr></tbody></table>

<mark style="color:$primary;">\*다음 달 정기 결제가 발생하지 않거나 최소 결제 금액보다 반영될 요금이 많을 경우 요금에 반영되지 않습니다.</mark>

{% hint style="info" %}
**연간 결제는 시트를 줄이실 수 없습니다**

1년치를 선결제하는 구조이므로 결제 주기 중에는 시트 삭제와 환불이 불가합니다.\
대신 비어 있는 시트에 **1년 이내 다른 학생을 등록**해 사용하시고, 다음 갱신 시점에 시트 수를 조정하시면 됩니다.

자세한 내용은 [시트 추가 · 삭제](/broken/pages/aaadc173a2ae771157ace3e768c2180d1b77dae7) 문서를 참고해 주세요.
{% endhint %}

### 6. 크레딧 처리

<table><thead><tr><th width="180">구분</th><th>처리</th></tr></thead><tbody><tr><td>기본 크레딧</td><td>환불 대상이 아니며, 구독 환불 시 회수됩니다.</td></tr><tr><td>추가 구매 크레딧</td><td>구매일로부터 30일 이내 미사용분에 한해 환불 가능합니다.</td></tr><tr><td>연간 결제 해지</td><td>잔여 기본 크레딧은 소멸되며, 사용분은 환불액에서 차감됩니다.</td></tr></tbody></table>

자세한 내용은 [수업 생성 크레딧(CP)](https://1hour.gitbook.io/guide/~/revisions/H6SuWSC7TrvHNKOtOJdh/teacher/billing/credit) 문서를 참고해 주세요.

### 7. 환불 신청 경로

환불은 관리자 페이지에서 직접 신청하실 수 없습니다.\
**채널톡 또는 담당 매니저**에게 문의해 주시면 확인 후 처리해 드립니다.

문의 시 아래 내용을 함께 알려주시면 빠르게 안내드릴 수 있습니다.

* 학원명 또는 계정 정보
* 환불을 원하시는 결제 건
* 종료를 희망하시는 시점

### 8. 구독 해지와 회원 탈퇴는 다릅니다

<table><thead><tr><th width="130">구분</th><th>구독 해지</th><th>회원 탈퇴</th></tr></thead><tbody><tr><td>대상</td><td>구독권만 종료</td><td>계정 전체 삭제</td></tr><tr><td>데이터</td><td>유지 (재결제 시 열람 가능)</td><td><strong>모두 삭제</strong></td></tr><tr><td>복구</td><td>재결제로 그대로 이용</td><td><strong>재가입해도 복구되지 않음</strong></td></tr><tr><td>처리 방법</td><td>직접 신청</td><td>고객센터 문의 필요</td></tr></tbody></table>

{% hint style="danger" %}
**회원 탈퇴는 되돌릴 수 없습니다**

탈퇴하시면 계정 내 모든 데이터와 권한이 삭제되며, 다시 가입하셔도 복구되지 않습니다.\
구독 요금만 중단하고 싶으시다면 **회원 탈퇴가 아닌 구독 해지**를 선택해 주세요.
{% endhint %}

### 자주 묻는 질문

<details>

<summary>해지했는데 환불이 안 됐어요.</summary>

구독 결제 관리에서 직접 해지하시면 해지 예약으로 처리됩니다.\
월간 결제는 당월 말일까지 이용하신 후 종료되며, 당월 결제분에 대한 환불은 없습니다.

전액 환불 조건(결제 후 영업일 2일 이내 또는 7일 이내 미사용)에 해당하시거나 연간 결제 중도 해지를 원하시면 채널톡으로 문의해 주세요.

</details>

<details>

<summary>결제한 지 얼마 안 됐는데 취소할 수 있나요?</summary>

결제 후 영업일 기준 2일 이내라면 사용 여부와 관계없이 전액 환불이 가능합니다.\
결제 후 7일 이내이면서 활동 이력이 없는 경우에도 전액 환불이 가능합니다.

</details>

<details>

<summary>학생을 삭제했는데 요금이 그대로예요.</summary>

학생 삭제와 시트 삭제는 별개입니다.\
학생을 삭제하시면 시트는 비어 있는 상태로 유지되고 요금은 변동되지 않습니다.

요금을 줄이시려면 관리자 페이지에서 시트 수를 함께 줄여 주셔야 합니다.\
자세한 방법은 [시트 추가 · 삭제](/broken/pages/aaadc173a2ae771157ace3e768c2180d1b77dae7) 문서를 참고해 주세요.

</details>

<details>

<summary>연간 결제 중간에 해지하면 얼마를 돌려받나요?</summary>

할인 전 정가를 기준으로 사용 기간을 환산하고, 사용하신 크레딧을 차감한 금액이 환불됩니다.\
자세한 계산 방식은 4-3 항목을 참고해 주세요.

</details>

<details>

<summary>연간 결제 중에 시트를 줄일 수 있나요?</summary>

연간 결제는 1년치를 선결제하는 구조이므로 결제 주기 중 시트 삭제와 환불이 불가합니다.\
비어 있는 시트에는 1년 이내 다른 학생을 등록해 사용하실 수 있으며, 다음 갱신 시점에 시트 수를 조정하실 수 있습니다.

</details>

<details>

<summary>남은 크레딧을 환불받을 수 있나요?</summary>

기본 크레딧은 환불 대상이 아닙니다.\
추가 구매하신 크레딧은 구매일로부터 30일 이내 미사용분에 한해 환불이 가능합니다.

</details>

<details>

<summary>해지 후 다시 이용할 수 있나요?</summary>

네, 언제든 다시 결제하시고 이용하실 수 있습니다.\
학생 계정과 수업 자료가 유지되어 있으므로 결제 후 그대로 이어서 사용하실 수 있습니다.

</details>

<details>

<summary>회원 탈퇴는 어떻게 하나요?</summary>

회원 탈퇴는 직접 처리하실 수 없으며 고객센터로 문의해 주셔야 합니다.\
탈퇴 시 계정 내 모든 데이터가 삭제되고 복구되지 않으니 신중하게 결정해 주세요.

</details>
