# 수업 생성 크레딧(CP)

원아워에서 AI를 활용해 수업과 문제를 만드실 때 사용되는 크레딧(CP) 안내입니다.

지급 기준, 사용량, 회수·환불 기준을 정리했습니다.

***

### 1. 수업 생성 AI 크레딧이란

수업 생성 AI 크레딧(CP)은 문제 생성, 수업 자료 생성 등 **AI로 수업 콘텐츠를 만들 때** 사용하는 크레딧입니다.

<table><thead><tr><th width="188.71875">항목</th><th>기준</th></tr></thead><tbody><tr><td>환산 기준</td><td>1 CP = 20원 (부가세 포함)</td></tr><tr><td>사용 대상</td><td>AI 수업 생성, AI 문제 생성</td></tr><tr><td>미적용 대상</td><td>커스텀 수업 생성, 학습지 출력, 학생 학습 활동, 학생용 AI 평가 기능</td></tr></tbody></table>

***

### 2. 크레딧 지급 기준

각 플랜에는 결제 금액의 일정 비율에 해당하는 **기본 크레딧**이 제공됩니다.

#### 아카데미 플랜

| 플랜          | 기본 크레딧 지급 비율  |
| ----------- | ------------- |
| Basic       | 결제 금액의 10% 상당 |
| Speaking AI | 결제 금액의 12% 상당 |
| Writing AI  | 결제 금액의 12% 상당 |
| AI Pro      | 결제 금액의 15% 상당 |

#### 비즈니스 파트너 플랜

비즈니스 파트너 플랜은 학생이 납부하는 요금 중 **원아워 이용료를 기준으로** 크레딧이 지급되며, 아카데미 플랜보다 높은 지급 비율이 적용됩니다.

| 플랜          | 기본 크레딧 지급 비율  |
| ----------- | ------------- |
| Basic       | 결제 금액의 15% 상당 |
| Speaking AI | 결제 금액의 17% 상당 |
| Writing AI  | 결제 금액의 17% 상당 |
| AI Pro      | 결제 금액의 20% 상당 |

#### 할인과 크레딧

크레딧은 **할인 적용 전 정가를 기준으로** 산정됩니다.

연간 결제로 10% 할인을 받으셔도 크레딧 지급량은 줄어들지 않습니다.

***

### 3. 지급 시점과 유효기간

| 구분                 | 지급 시점          | 유효기간                 |
| ------------------ | -------------- | -------------------- |
| 월간 결제 기본 크레딧       | 매월 1일 오전 10시   | **당월 말까지** (이월 불가)   |
| 연간 결제 기본 크레딧       | 결제 시 1년치 일괄 지급 | 연간 이용 기간 만료 시 잔여분 소멸 |
| 비즈니스 파트너 플랜 기본 크레딧 | 학생 결제 시점       | **당월 말까지** (이월 불가)   |
| 추가 구매 크레딧          | 구매 즉시          | **구매일로부터 1년**        |

* 시트를 추가하시면 추가 결제 금액에 해당하는 크레딧도 함께 지급됩니다.
* 기본 크레딧은 지급 당월(또는 연간 이용 기간)에만 사용 가능하며, 남은 크레딧은 이월되지 않고 소멸됩니다.

### 4. 크레딧은 실제로 얼마나 제공되나요

학원 규모별로 매월 제공되는 기본 크레딧 예시입니다. (아카데미 플랜, 1 CP = 20원 기준)

| 시트 수 | Basic (10%) | Speaking · Writing AI (12%) | AI Pro (15%) |
| ---- | ----------- | --------------------------- | ------------ |
| 10개  | 약 295 CP    | 약 474 CP                    | 약 743 CP     |
| 30개  | 약 885 CP    | 약 1,422 CP                  | 약 2,228 CP   |
| 50개  | 약 1,475 CP  | 약 2,370 CP                  | 약 3,713 CP   |
| 100개 | 약 2,950 CP  | 약 4,740 CP                  | 약 7,425 CP   |

기본 크레딧으로 수업 생성이 가능하며, 그 이상이 필요하실 때만 추가 구매를 진행하시면 됩니다.

**예시** — 시트 30개로 Speaking AI 플랜을 사용하는 학원의 경우, 5분짜리 유튜브 영상에 내용이해 객관식 10문제를 붙인 수업을 한 달에 약 28개 만드실 수 있습니다.

### 5. 크레딧은 언제 사용되나요

크레딧은 AI가 작동하는 두 단계에서 사용됩니다.

**1단계 — 수업 생성** 영상·음원·PDF·이미지 등을 업로드하여 수업 자료를 만드는 과정에서 AI가 작동합니다.

**2단계 — 문제 생성** 만들어진 수업 자료를 바탕으로 문제를 생성할 때 AI가 작동합니다.

각 단계는 독립적으로 차감되며, 단계가 실패해 결과물이 생성되지 않은 경우에는 차감되지 않습니다.

#### 실전 예시

### 7. 문제 생성 시 예상 크레딧 (문제 유형별)

1세트는 문제 유형 한 가지를 한 번 생성하는 단위로, 보통 10\~20문제가 함께 생성됩니다.

| 문제 유형           | 1세트 문제 수 | 1세트 예상 CP |
| --------------- | -------- | --------- |
| 내용이해 T/F        | 10문제     | 20 CP     |
| 내용이해 객관식        | 10문제     | 20 CP     |
| 키즈 내용이해 / T/F   | 10문제     | 20 CP     |
| 영어 해설 (객관식·T/F) | 10문제     | 10 CP     |
| 단어 (쓰임·영영풀이)    | 10문제     | 50 CP     |
| 문법 (본문분석·연습·기출) | 20문제     | 60 CP     |
| 파이널 내신·수능       | 20문제     | 80 CP     |
| 내용이해 기출형        | 20문제     | 80 CP     |

#### 동형 모의고사

동형 모의고사는 문제를 직접 추가하는 방식으로, 기본 문제 수가 지정되어 있지 않습니다.

| 문제 유형   | 문제 1개당 CP | 1세트 예상 CP (20문제 기준) |
| ------- | --------- | ------------------- |
| 동형 모의고사 | 25 CP     | 500 CP              |

문제 수가 많은 유형은 사용량이 빠르게 늘어날 수 있으니 미리 확인해 주시면 좋습니다.

| 사용 순서 | 기본 크레딧 우선 차감 후 추가 구매 크레딧 차감          |

### 9. 크레딧 회수

아래 경우에는 이미 지급된 기본 크레딧이 회수됩니다.

| 상황                | 처리                          |
| ----------------- | --------------------------- |
| 구독 환불             | 해당 결제로 지급된 기본 크레딧 회수        |
| 연간 결제 중도 해지       | 잔여 기본 크레딧 소멸, 사용분은 환불액에서 차감 |
| 결제 실패 · 결제 취소     | 해당 건으로 지급된 크레딧 미지급 또는 회수    |
| 비즈니스 파트너 플랜 학생 환불 | 해당 학생분 크레딧 즉시 회수            |

#### 회수되지 않는 경우

#### 잔액이 부족한 상태에서 회수되는 경우

이미 크레딧을 사용하신 뒤 회수가 발생하면 잔액이 마이너스로 표시될 수 있습니다.

* 마이너스 크레딧은 **50 CP 이상일 때 매일 오전 9시에 일괄 청구**됩니다.
* 마이너스 상태에서는 AI 수업 생성 기능이 제한됩니다.

비즈니스 파트너 플랜은 학생 환불이 실시간으로 반영되므로, 이미 크레딧을 사용하신 뒤 학생 환불이 발생하면 마이너스가 생길 수 있습니다.

### 10. 크레딧 환불

| 구분        | 환불 가능 여부                                |
| --------- | --------------------------------------- |
| 기본 크레딧    | **환불 대상이 아닙니다** (지급 비율에 따라 무상 제공되는 크레딧) |
| 추가 구매 크레딧 | **구매일로부터 30일 이내 미사용분에 한해 환불 가능**        |
| 소멸된 크레딧   | 환불 대상이 아닙니다                             |

#### 추가 구매 크레딧 환불 기준

* 환불 기준일은 **구매일**입니다. 여러 번 나누어 구매하신 경우 각 구매 건별로 30일을 계산합니다.
* 이미 사용하신 크레딧은 환불되지 않으며, 미사용 잔액 기준으로만 환불됩니다.
* 환불 금액은 1 CP = 20원 기준으로 환산됩니다.

#### 신청 경로

크레딧 환불은 관리자 페이지에서 직접 신청하실 수 없습니다. 채널톡 또는 담당 매니저에게 문의해 주시면 확인 후 처리해 드립니다.

### 11. 생성 결과에 문제가 있는 경우

AI가 만든 결과물에 문제가 있을 때는 신고를 통해 확인을 요청하실 수 있습니다.

#### 자동 처리되는 경우

생성이 실패하여 결과물이 만들어지지 않은 경우에는 크레딧이 차감되지 않습니다. 별도 신고가 필요하지 않습니다.

#### 신고가 필요한 경우

결과물은 생성되었으나 내용에 문제가 있는 경우입니다.

<table><thead><tr><th width="277.1328125">항목</th><th>기준</th></tr></thead><tbody><tr><td>신고 경로</td><td>해당 수업 상세 페이지 내 신고 버튼</td></tr><tr><td>신고 기간</td><td>생성 시점으로부터 <strong>30일 이내</strong></td></tr><tr><td>신고 단위</td><td>수업 단위 · 문제 단위(문제 세트별)</td></tr><tr><td>처리 기간</td><td>영업일 기준 2일 이내</td></tr></tbody></table>

#### 처리 순서

1. 신고 내용과 실제 결과물을 확인합니다.
2. 확인된 경우 **무료로 1회 재생성**해 드립니다.
3. 재생성 후에도 동일한 문제가 확인되면 **사용된 크레딧을 환불**해 드립니다.

2026년 8월 1일 이전에 생성된 수업은 신고와 재생성은 가능하나, 크레딧 환불 대상에는 해당하지 않습니다.

### 12. 크레딧 수치는 어떻게 정해지나요

원아워의 AI 기능은 OpenAI 등 외부 AI 서비스를 활용해 제공됩니다. 외부 AI 사용료는 처리되는 토큰(텍스트·음성·이미지의 단위)에 따라 달러로 결제되며, 원아워는 이 비용을 기준으로 크레딧을 산정하고 있습니다.

이러한 구조 때문에 크레딧 수치는 환율과 외부 AI 사용료에 따라 변동될 수 있습니다. 예를 들어 어제 내용이해 T/F 10문제 생성에 20 CP가 사용되었더라도, 환율이 오른 다음 날에는 동일한 작업에 24 CP가 사용될 수 있습니다.

본 문서의 수치는 평균 예상치이며, 실제 차감되는 크레딧은 작업 시점의 환율과 사용료에 따라 달라질 수 있다는 점을 참고해 주시면 감사하겠습니다.

* 위 수치는 2026년 5월 사용 데이터를 기준으로 한 평균 예상치입니다.
* 자료의 분량과 내용, 작업 시점의 환율에 따라 실제 사용량은 달라질 수 있습니다.

### 13. 자주 묻는 질문

**기본 크레딧을 다 쓰면 어떻게 되나요?**

추가 크레딧을 구매하셔야 AI 수업 생성 기능을 계속 이용하실 수 있습니다. 추가 구매한 크레딧은 1년간 유효합니다.

**기본 크레딧이 남으면 다음 달로 이월되나요?**

이월되지 않고 당월 말에 소멸됩니다. 별도로 구매하신 추가 크레딧은 1년간 유효합니다.

**연간 결제를 하면 크레딧이 적게 지급되나요?**

아닙니다. 크레딧은 할인 전 정가를 기준으로 산정되므로 할인 여부와 관계없이 동일하게 지급됩니다.

**학습지를 출력할 때도 크레딧이 차감되나요?**

차감되지 않습니다. 크레딧은 AI 수업 생성과 AI 문제 생성에만 사용됩니다.

**플랜을 다운그레이드하면 이미 받은 크레딧이 회수되나요?**

당월에 지급된 크레딧은 회수되지 않습니다. 다음 달부터 변경된 플랜의 지급 비율이 적용됩니다.

**남은 크레딧을 환불받을 수 있나요?**

기본 크레딧은 환불 대상이 아닙니다. 추가 구매하신 크레딧은 구매일로부터 30일 이내 미사용분에 한해 환불이 가능합니다.

**크레딧 잔액이 마이너스로 표시됩니다.**

크레딧을 사용하신 뒤 결제 취소나 환불이 발생하면 잔액이 마이너스가 될 수 있습니다.

마이너스 크레딧은 50 CP 이상일 때 매일 오전 9시에 일괄 청구되며, 청구가 완료되면 잔액이 정상화됩니다.

**같은 수업을 다시 만들면 크레딧이 또 차감되나요?**

차감됩니다. 다만 생성 결과에 문제가 있어 신고해 주신 경우에는 1회 무료로 재생성해 드립니다.
