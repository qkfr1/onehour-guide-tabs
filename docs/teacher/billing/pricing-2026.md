## 9. 수업 생성 AI 크레딧

각 요금제에는 월 결제 금액의 일정 비율에 해당하는 기본 크레딧이 매월 기본 제공되며, 지급 당월에 한해 이용하실 수 있습니다.\
**기본 제공량을 초과해 사용하시는 경우에만 추가 크레딧 구매가 필요**합니다. 추가 구매 크레딧은 1년 간 유효합니다.

## 10. 해지 및 환불

#### 10-1. 전액 환불 기준

아래 조건에 해당하는 경우 전액 환불이 가능합니다. 월간·연간 결제 모두 동일하게 적용됩니다.

| 조건                           | 가능 여부 |
| ---------------------------- | ----- |
| 결제 후 영업일 기준 2일 이내 (사용 여부 무관) | 전액 환불 |
| 결제 후 7일 이내이며 활동 이력이 없는 경우    | 전액 환불 |
| 이전 달 결제분                     | 환불 불가 |

#### 10-2. 월간 결제 중도 해지

| 구분    | 처리                   |
| ----- | -------------------- |
| 이용 기간 | 당월 말일까지 이용 가능        |
| 청구    | 익월부터 청구되지 않음         |
| 환불    | 당월 결제분에 대한 별도 환불은 없음 |

#### 10-3. 연간 결제 중도 해지

연간 결제는 할인 적용 전 정가 기준으로 사용 기간을 환산한 뒤, 사용하신 크레딧을 차감하여 환불액을 산정합니다.

```
환불액 = 결제 금액 − 사용 기간 정가 환산액 − 사용 크레딧 환산액

  · 사용 기간 정가 환산액 = (정가 연 이용료 × 시트 수 ÷ 365) × 사용 일수
  · 사용 크레딧 환산액 = 사용 크레딧(CP) × 20원
```

**계산 예시**

AI Pro 플랜, 시트 30개, 연간 결제 후 152일 사용, 크레딧 3,000 CP 사용 시

| 항목                                    | 금액             |
| ------------------------------------- | -------------- |
| 결제 금액 (106,920원 × 30개)                | 3,207,600원     |
| 정가 기준 연 이용료 (118,800원 × 30개)          | 3,564,000원     |
| 사용 기간 정가 환산액 (3,564,000 ÷ 365 × 152일) | −1,484,186원    |
| 사용 크레딧 환산액 (3,000 CP × 20원)           | −60,000원       |
| **환불액**                               | **1,663,414원** |

#### 10-4. 시트 삭제 시 환불

| 구분    | 처리                            |
| ----- | ----------------------------- |
| 월간 결제 | 일할 계산하여 익월 정산에 환불 반영          |
| 연간 결제 | 환불 불가, 1년 이내 다른 학생을 등록해 사용 가능 |

학생 삭제는 환불 대상이 아닙니다. 학생을 삭제하셔도 시트는 유지되며 요금이 변동되지 않습니다.\
\*다음 달 정기 결제가 발생하지 않거나 최소 결제 금액보다 반영될 요금이 많을 시 요금에 반영되지 않습니다.

#### 10-5. 크레딧 처리

| 구분        | 처리                                |
| --------- | --------------------------------- |
| 기본 크레딧    | 환불 대상이 아니며, 구독 환불 시 회수됩니다         |
| 추가 구매 크레딧 | 구매일로부터 30일 이내 미사용분에 한해 환불 가능      |
| 연간 결제 해지  | 잔여 기본 크레딧은 소멸되며, 사용분은 환불액에서 차감됩니다 |

자세한 내용은 \[[크레딧(CP) 안내](credit.md)] 문서를 참고해 주세요.

#### 10-6. 환불 신청 경로

환불은 관리자 페이지에서 직접 신청하실 수 없습니다. 채널톡 또는 담당 매니저에게 문의해 주시면 확인 후 처리해 드립니다.

## 자주 묻는 질문

**최소 몇 개 시트부터 이용할 수 있나요?**

모든 플랜은 시트 10개부터 이용 가능합니다. 학생이 10명 미만이시더라도 최소 10개 시트 기준으로 청구됩니다.

**학생을 삭제했는데 요금이 그대로예요.**

학생 삭제와 시트 삭제는 별개입니다. 학생을 삭제하시면 시트는 비어 있는 상태로 유지되고 요금은 변동되지 않습니다.

요금을 줄이시려면 관리자 페이지에서 시트 수를 함께 줄여 주셔야 합니다.

**학생을 추가하면 바로 요금이 늘어나나요?**

비어 있는 시트가 남아 있다면 추가 요금이 발생하지 않습니다.

보유 시트를 모두 사용 중인 상태에서 학생을 추가하시면 시트 추가가 필요하며, 이때 일할 계산되어 즉시 결제됩니다.

**같은 달에 시트를 추가하고 삭제하면 상계되나요?**

상계되지 않습니다. 시트 추가는 즉시 결제되고, 시트 삭제는 익월 정산에 환불로 반영됩니다.

**연간 결제 중에 시트를 줄일 수 있나요?**

연간 결제는 1년치를 선결제하는 구조이므로 결제 주기 중 시트 삭제와 환불이 불가합니다.

비어 있는 시트에는 1년 이내 다른 학생을 등록해 사용하실 수 있으며, 다음 갱신 시점에 시트 수를 조정하실 수 있습니다.

**연간 결제와 월 결제 중 무엇이 더 유리한가요?**

연간 결제는 10% 할인이 적용되어 1년 기준으로 더 저렴합니다.

다만 결제 주기 중 시트를 줄이실 수 없으므로, 학생 수 변동이 큰 학원은 월 결제가 더 유연할 수 있습니다.

**플랜을 바꾸면 기존 과제는 어떻게 되나요?**

이미 완료된 과제의 결과는 영구 보존됩니다.

다운그레이드 시 새 플랜에서 사용할 수 없는 AI 기능이 포함된 과제만 다음 결제일부터 비활성화됩니다.

**연간 결제 중간에 해지하면 얼마를 돌려받나요?**

할인 전 정가를 기준으로 사용 기간을 환산하고, 사용하신 크레딧을 차감한 금액이 환불됩니다.

자세한 계산 방식은 10-3을 참고해 주세요.

**기본 크레딧이 남으면 다음 달로 이월되나요?**

월간 결제의 기본 크레딧은 지급 당월에만 사용 가능하며 이월되지 않습니다.

별도로 구매하신 추가 크레딧은 1년간 유효합니다.
