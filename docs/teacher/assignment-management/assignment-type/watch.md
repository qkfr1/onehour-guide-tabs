# 콘텐츠 시청 과제

### 콘텐츠 시청 과제란?

수업에 포함된 영상 또는 음원을 학생이 끝까지 시청하도록 과제로 부여하는 기능입니다.

#### 학생 화면에서 체험하기

{% @storylane/embed subdomain="app" linkValue="qdxjuqsngl0y" url="https://app.storylane.io/share/qdxjuqsngl0y" %}

#### 학생이 열심히 콘텐츠를 시청했는지 어떻게 확인하나요?

1. 미시작 상태에서는 **과제 시작**, 진행 중에는 **이어서 하기** 버튼이 표시됩니다.
2. **영상 앞으로 건너뛰기가 차단**됩니다. 클릭 시 "영상을 처음부터 끝까지 시청해야 해요" 안내가 표시됩니다.
3. 다른 탭으로 이동하면 영상이 자동으로 일시정지됩니다. 탭으로 돌아오면 직접 재생 버튼을 눌러야 합니다.
4. **중간에 나가면** 과제가 완료처리 되지 않고 **수행 중 상태로 저장**되며 이어서 볼 수 있습니다.

#### 학생 화면에서 되돌아가 다시 보기

학생은 이미 본 구간 안에서 원하는 지점으로 되돌아가 다시 볼 수 있습니다.&#x20;

아직 보지 않은 구간으로는 건너뛸 수 없습니다.

{% hint style="info" %}
5초 앞/뒤 이동 버튼은 **영상만 있는 콘텐츠**에서 나타납니다. PDF가 함께 있는 콘텐츠와 음원만 있는 콘텐츠는 진행바를 눌러 이동하는 것만 됩니다.
{% endhint %}

**아직 보지 않은 구간을 누르면**

재생 위치는 바뀌지 않고 화면 위쪽 가운데에 「아직 보지 않은 구간이에요」 안내가 잠깐 표시됩니다.&#x20;

처음 보는 동안(되돌아가지 않은 상태)에는 \[5초 앞으로] 버튼이 항상 흐리게 표시되며, 눌러도 같은 안내가 나옵니다.



**진도와 학습시간은 이렇게 저장됩니다**

| 상황                | 저장 기준                                    |
| ----------------- | ---------------------------------------- |
| 되돌아가 다시 볼 때       | 진도는 줄지 않습니다. 가장 멀리 본 지점을 기준으로 저장합니다.     |
| 중간에 나갔다가 다시 들어올 때 | 가장 멀리 본 지점부터 이어서 봅니다. 되돌려 둔 위치는 남지 않습니다. |
| 학습시간              | 되돌아가 다시 본 시간도 학습시간에 더해집니다.               |

### 어떤 수업으로 콘텐츠 시청 과제를 낼 수 있나요?

영상 또는 음원이 포함된 수업에만 콘텐츠 시청 과제를 부여할 수 있습니다.

| 과제 부여 가능 O    | 과제 부여 불가 x     |
| ------------- | -------------- |
| 유튜브·비메오·영상 수업 | PDF만 있는 수업     |
| PDF + 영상 수업   | 이미지·텍스트 수업     |
| PDF + 음원 수업   | 유튜브 비공개·삭제된 영상 |
| 음원 수업         |                |

{% hint style="info" %}
과제를 낼 수 없는 수업을 선택하고 과제 내기 시 콘텐츠 학습 섹션 자체가 표시되지 않습니다.
{% endhint %}

### 자주 묻는 질문

**Q. 영상이 걸거나 짧아도 동일하게 동작하나요?**

네, 영상 길이와 관계없이 동일한 정책이 적용됩니다.

**Q. 과제가 완료된 후 학생이 영상을 다시 볼 수 있나요?**

완료된 과제로는 재진입이 불가합니다. 영상을 다시 보려면 \[학습 기능] - \[수업 시작]을 이용해 시청해주세요.

**Q. 반복 시청 과제에서 1회차를 다 보면 2회차는 앞으로 건너뛸 수 있나요?**

아니요. 회차를 이어서 하나의 진행으로 셉니다. 1회차를 끝까지 본 학생은 2회차 시작 지점까지 본 것으로 계산되므로 2회차에서 앞으로 건너뛸 수 없습니다. 대신 2회차를 보다가 1회차 구간으로 되돌아가 다시 볼 수는 있습니다.

**Q. 학생이 되감기를 하면 진도가 처음으로 돌아가나요?**

아니요. 되돌아가도 진도는 가장 멀리 본 지점을 기준으로 저장됩니다. 과제 관리의 완료율도 줄지 않습니다.
