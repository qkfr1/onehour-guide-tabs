# 커스텀\_수업\_생성

원하는 단어, 문장, 문제를 직접 넣어 나만의 수업을 만드는 방법을 안내합니다.

{% hint style="info" %}
커스텀 생성 시에는 별도의 크레딧이 차감되지 않습니다.
{% endhint %}

{% hint style="warning" %}
커스텀 수업은 업로드한 콘텐츠에서 학습할 데이터가 자동으로 추출되지 않습니다. 자동 추출을 원하시면 커스텀이 아닌 다른 수업 생성 유형을 이용해 주세요.
{% endhint %}

단어와 문장은 이 문서에서, 문제는 [문제 세트 만들기](/broken/pages/c3d08dcb80c8509d82baa85ccfb8f102c7f480d1)에서 안내합니다.

## 1. 커스텀 수업 만들기

{% stepper %}
{% step %}
## 좌측 사이드바에서 **+ 수업 생성** 버튼을 클릭합니다.
{% endstep %}

{% step %}
## **영역별 수업**의 **커스텀**을 클릭합니다.
{% endstep %}

{% step %}
## **수업 제목 (필수)** 에 수업 이름을 입력합니다.

커스텀 수업 생성에서 필수 입력 항목은 수업 제목뿐입니다.
{% endstep %}

{% step %}
## **수업 형식 (선택)** 에서 수업에 사용할 콘텐츠 형식을 선택합니다.

PDF / PDF + 음원 / 영상 / 유튜브 링크 / 음원 / 이미지 중에서 고를 수 있습니다. 선택하지 않아도 수업을 만들 수 있습니다.
{% endstep %}

{% step %}
## **콘텐츠 업로드** 영역에 파일을 올립니다.

드래그하거나 클릭해 업로드합니다. PDF는 50MB 이하만 등록됩니다. 업로드한 파일을 바꾸려면 **다시 올리기**를 클릭합니다.
{% endstep %}

{% step %}
## **썸네일 추가 (선택)** 영역에 대표 이미지를 올립니다.

이미지를 드래그하거나 클릭해 업로드합니다. JPG, PNG, JPEG 형식을 지원합니다.
{% endstep %}

{% step %}
## **수업 생성** 버튼을 클릭합니다.
{% endstep %}
{% endstepper %}

## 2. 문장 추가하기

수업이 생성되면 **수업 수정** 화면으로 이동합니다. **문장** 탭에서 학습할 문장을 추가합니다.

{% hint style="warning" %}
* 특수 문자 #, ,."'!?-:;$%)(@、。와 숫자, 한국어, 영어만 지원됩니다.
* 이미 과제를 출제한 수업은 문장을 합칠 수 없습니다.
* 음원·영상 수업은 문장 수정 후 **싱크 탭**에서 확인이 필요합니다. 싱크가 맞지 않으면 과제 오류가 발생합니다.
{% endhint %}

문장을 추가하는 방법은 두 가지입니다. 문장을 한 개씩 넣는 **개별 추가**와, 가지고 있는 문장 전체를 통으로 넣어 자동 분할하는 **붙여넣기**입니다.

### 방법 1. 개별 추가

{% stepper %}
{% step %}
## **문장** 탭을 클릭합니다.
{% endstep %}

{% step %}
## **문장 추가 +** 를 클릭합니다.
{% endstep %}

{% step %}
## 왼쪽 **학습 문장** 영역에 영어 문장을, 오른쪽 **번역 문장** 영역에 한글 번역을 입력합니다.
{% endstep %}

{% step %}
## **저장하기**를 클릭합니다.

입력한 문장이 수업에 저장됩니다.
{% endstep %}
{% endstepper %}

### 방법 2. 붙여넣기로 한 번에 추가

{% stepper %}
{% step %}
## **붙여넣기**를 클릭합니다.
{% endstep %}

{% step %}
## 복사한 텍스트를 그대로 붙여넣고 **추가하기**를 클릭합니다.

AI가 영어와 한글 문장을 자동으로 분리하여 추가합니다.
{% endstep %}

{% step %}
## 입력한 문장이 자동으로 분할되어 추가된 것을 확인합니다.
{% endstep %}

{% step %}
## **문장 번역**을 클릭해 번역을 자동으로 추가합니다.
{% endstep %}

{% step %}
## **저장하기**를 클릭해 저장되지 않은 문장을 저장합니다.
{% endstep %}
{% endstepper %}

## 3. 단어 추가하기

**단어** 탭에서 학습할 단어를 추가합니다. 단어를 추가하는 방법도 직접 입력과 단어 추출 AI 두 가지입니다.

{% hint style="info" %}
단어는 최대 500개까지 등록할 수 있습니다. 중복된 단어는 추가 시 자동으로 제외됩니다.
{% endhint %}

{% stepper %}
{% step %}
## **단어** 탭을 클릭합니다.
{% endstep %}
{% endstepper %}

### 방법 1. 직접 입력

{% stepper %}
{% step %}
## 왼쪽 영역에 영어 단어를, 오른쪽 영역에 한글 뜻을 입력합니다.

직접 입력하거나 복사 후 붙여넣기(Ctrl+V)를 해도 됩니다.
{% endstep %}

{% step %}
## **추가**를 클릭해 저장합니다.
{% endstep %}
{% endstepper %}

### 방법 2. 단어 추출 AI

{% stepper %}
{% step %}
## **단어 추출 AI**를 클릭합니다.

저장한 문장에서 학습할 단어를 자동으로 추출합니다. 추출할 단어의 난이도(하·중·상)와 단어 수(15·30·50)를 지정할 수 있습니다.
{% endstep %}

{% step %}
## 자동 추출된 단어를 확인하고 **추가**를 클릭합니다.
{% endstep %}

{% step %}
## **추가한 단어 목록**에서 추가된 단어를 확인합니다.

단어 검색, 선택 삭제하기, 전체 삭제하기, 미리보기를 이용할 수 있습니다.
{% endstep %}
{% endstepper %}

## 4. 문제 추가하기

커스텀 수업에는 단어와 문장뿐 아니라 문제도 직접 넣을 수 있습니다. 수업 수정 화면 상단의 **문제 세트 편집**을 클릭하면 문제 생성 화면으로 이동합니다.

## 5. 생성한 수업 확인하기

{% stepper %}
{% step %}
## 좌측 사이드바에서 **수업관리**를 클릭합니다.
{% endstep %}

{% step %}
## **내가 만든 수업**에서 수업명을 클릭합니다.
{% endstep %}

{% step %}
## 직접 추가한 단어와 문장을 확인합니다.

## 6. 수업 수정하기

{% hint style="warning" %}
과제를 낸 수업을 수정하면 과제에 영향을 줄 수 있습니다. 과제를 낸 수업을 수정했다면 과제를 다시 내주세요.
{% endhint %}

{% stepper %}
{% step %}
## **수정하기**를 클릭합니다.
{% endstep %}

{% step %}
## 「수업 수정 시 주의사항」 안내를 확인하고 **수업 수정**을 클릭합니다.

수업을 수정하면 이미 출제된 과제의 내용과 다를 수 있습니다. 학생들의 리포트에 영향을 주지 않도록 수정 내용은 수정 후 새로 낸 과제에 반영됩니다.
{% endstep %}

{% step %}
## 문장과 단어를 편집합니다.

수업 수정 방법은 생성 방법과 동일합니다. 위 2·3·4번 항목을 참고해 주세요.
{% endstep %}
{% endstepper %}

## 자주 묻는 질문

<details>

<summary>커스텀 수업 생성에도 크레딧이 차감되나요?</summary>

차감되지 않습니다. 커스텀 생성 시에는 별도의 크레딧이 차감되지 않습니다.

</details>

<details>

<summary>PDF를 올렸는데 단어와 문장이 자동으로 만들어지지 않아요.</summary>

커스텀 수업은 업로드한 콘텐츠에서 학습 데이터를 자동으로 추출하지 않습니다. 자동 추출을 원하시면 「교재 가져오기」, 「단어장」 등 다른 수업 생성 유형을 이용해 주세요.

</details>

<details>

<summary>수업 제목 말고 꼭 넣어야 하는 항목이 있나요?</summary>

없습니다. 수업 제목만 필수이며 수업 형식, 콘텐츠, 썸네일은 모두 선택입니다.

</details>
